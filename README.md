# Arduino Traffic Signal Controller 🚦

A simple traffic signal automation system built using Arduino Uno and LEDs.

## Components Used
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- 220Ω Resistors
- Breadboard
- Jumper wires

## Features
- Automated traffic light sequence
- Timed signal transitions
- Embedded control logic simulation

## Working Principle
The system simulates a real-world traffic signal using sequential timing logic:
1. Green signal for vehicle movement
2. Yellow signal as warning
3. Red signal to stop vehicles

## Concepts Learned
- Arduino digital output
- Embedded timing control
- Sequential automation
- State-based logic
